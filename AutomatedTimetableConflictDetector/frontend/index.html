Project Overview

The Automated Timetable Conflict Detector lets college coordinators add and manage schedules while automatically checking for overlapping Faculty, Classroom, and Section bookings in Core Java.

Conflict Detection Logic

In ConflictDetector.java, entries stored in an ArrayList are compared using nested loops on the same day with LocalTime: 

start1 < end2 && start2 < end1

Back-to-back classes (e.g., 09:00–10:00 and 10:00–11:00) do not conflict.
